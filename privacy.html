Privacy Policy

Last updated: October 14, 2026

This policy describes the intended handling of information by DriveVault. The operator must verify that it accurately reflects the deployed software before inviting public users.

Information processed

Depending on features used, DriveVault may process Telegram user IDs and commands, Google OAuth tokens, Drive file/folder names and IDs, metadata, and files needed to perform actions requested by the user.

Use and storage

This information may be used to authenticate users, connect Google Drive, perform requested file operations, and troubleshoot the service. Depending on deployment, tokens and operational data may be processed or stored on the bot host and OAuth callback service. The operator must secure access, set retention periods, and delete data when no longer needed.

Sharing

DriveVault does not intend to sell personal information. Infrastructure providers may process data to run the service. Update this policy if actual practices differ.

Google user data

Google user data should be used only to provide requested Drive features and handled according to Google's applicable API Services User Data Policy, including Limited Use requirements where applicable.

Deletion and revocation

Contact the operator to request account disconnection and deletion of associated data. Deleting a local token may not revoke authorization in Google Account settings; users can separately remove the app's access from their Google Account.
