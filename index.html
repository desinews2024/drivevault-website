DriveVault

DriveVault is a Telegram bot project intended to help users manage files with Google Drive.

Status: Development/testing. Public multi-user access is not available until the deployed bot is updated and tested for separate user accounts.

How it works

When enabled, DriveVault may request Google Drive access to perform actions requested through the bot. Review Google's permission screen and only continue if you trust the operator.
